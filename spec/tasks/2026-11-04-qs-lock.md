# qs ロックの限定更新

Actio: `actio:88ece5a5-f64e-4e08-8079-224ffb7671b6`

`qs` のロックを 6.15.3 から 6.16.2 へ更新する。`body-parser@2.3.0` の
`^6.15.2` と `express` の `^6.14.0` に収まるため、親依存・manifest・overrides は変更しない。
公開 npm registry の固定版 metadata と照合し、version / resolved / integrity だけを更新する。
依存パッケージ、Node 要件、ライセンスは変わらない。

## 契約と最小検証

C-1 verifyQsLock(before, after): qs の固定版と公開 integrity を更新し、既存要求範囲と他のロック情報を維持する

Augur plan の回帰検証案に従い、`scripts/qs-lock/tests/verify.ts` で旧版の拒否、更新版の受理、
integrity の不一致、親の要求範囲変更、無関係なロック変更の拒否を確認する。
契約は `scripts/qs-lock/augur.contracts.json` に分離し、既存の Web 契約を変更しない。
既存の Augur contract runtime と Node 標準 API を再利用する。依存追加や独自 semver 実装は不要。

実行: `node scripts/qs-lock/tests/verify.ts`（着手時のローカル main `c4b8eb8` との比較）。
サービス起動、ライフサイクルスクリプト、全体テスト、依存パッケージの実行は行わない。
