# Anatomia とは

<a id="what"></a>
## できること

Anatomia は、リポジトリのコードを関数ごとに解析し、次の 2 つを手伝います。

- **書く前（supply）**: 作業の説明から、どのドメイン（機能のまとまり）に属するか、どの決まりが効くか、
  手本にできる既存の関数、影響が及ぶ範囲、すでにある似た処理を返します。
- **書いた後（verify）**: 変更差分を 5 つの観点（規約・重複・仕様との結びつき・結合の増え方・
  周りとの書き方の一致）で検査し、外れている箇所を関数単位で示します。

主な利用者は、コードを書く AI セッション（Claude Code / Codex）と、その結果を確かめる人です。
入口はコマンドライン（CLI）、AI ホストからの MCP、ブラウザの管理パネルの 3 つです。

<a id="limits"></a>
## 知っておくこと

- 結果は「決まりに沿っているか」の機械的な判定です。設計の良し悪しの最終判断は人が行います。
- 「呼び出し元が無い」は「静的に呼び出しを証明できない」という意味で、使われていない断定ではありません。
- 解析できなかった場合は空の結果を返さず、失敗として知らせます。
